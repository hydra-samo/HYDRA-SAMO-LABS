# FAVICON — Browser & Pinned-Tile Set

| File | Use |
| --- | --- |
| `favicon.svg` | Primary (SVG) favicon |
| `favicon.ico` | ICO multi-res 16/32/48/64 |
| `favicon-16/32/48.png` | Legacy PNG favicons |
| `apple-touch-icon.png` | iOS home screen (180, abyssal tile) |
| `android-chrome-192/512.png` | Android / Chrome |
| `mstile-70/150/310.png`, `mstile-wide-310x150.png` | Windows pinned tiles |
| `mask-icon.svg` | Safari mask (black) |
| `site.webmanifest` | PWA manifest (abyssal `#060c09` theme) |
| `browserconfig.xml` | Windows tile config |

Backgrounds are abyssal `#060c09` tile where platforms require them.
