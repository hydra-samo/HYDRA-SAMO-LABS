# BRAND BOOK MAINTENANCE POLICY

The Brand Book is not a one-time deliverable.

It is a version-controlled publication.

Whenever the repository changes through an approved engineering phase:

• regenerate the Brand Book,

• merge the new documentation,

• preserve existing chapters,

• update only the affected sections,

• increment the publication version if appropriate,

• regenerate the PDF, HTML, and Markdown editions.

The Brand Book must never become outdated relative to the repository.

It remains the single authoritative publication for all stakeholders while the individual markdown files remain the authoritative engineering source documents.
