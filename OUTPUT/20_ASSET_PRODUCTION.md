# CAPABILITY-AWARE EXECUTION

Generate every asset that the current execution environment can natively produce.

If an asset requires proprietary software or unavailable tooling (such as .ai, .fig, .aep, .riv):

• never fabricate the file

• create its destination folder

• generate a README.md explaining why it cannot be generated automatically

• explain how to create it manually from the certified master SVG

• continue the production pipeline

The production pipeline must never falsely report unsupported assets as generated.
