## Typography

- Wordmark: **HYDRA SAMO**, Space Grotesk **700**, uppercase, tracking **`-0.02em`** (Brand Book §11.2).
- Built from the **Google Fonts v2.000 build** of Space Grotesk Bold — the exact
  typeface the website wordmark renders (`index.html` loads it from Google Fonts).
- Wordmark is vectorized to paths — no font dependency. The source font is kept
  in `source/` (with OFL 1.1) for regeneration.

## Geometry & Spacing

- The 4 certified mark paths are embedded **byte-identical** to the master (verified).
- Mark frame height: `172u` (horizontal) / `234u` (vertical) of the `1400×560` / `900×900` artboards.
- Clear space: **one hex-core unit** (17 mark units) between mark and wordmark and around the lockup, scaled with the mark.
- Both lockups are optically centered on the artboard (verified to ±0.5px).

## Restrictions

- Never split, recolor, re-trace, or rotate the mark; the wordmark is never italicized or distorted.
- Below the minimum mark size (24px UI / 16px favicon) use wordmark-only.
- The currentColor variant resolves to black in static raster/PDF renders — use it only in live web contexts.
- No effects are baked in — glow/reflection stay external in CSS.
