# Rotation Is Forbidden

Governance: the `.hydra-mark-spin` continuous-rotation utility is **retired** and must not be reintroduced.

**Rationale.** The 3-fold mark is rotationally self-similar: spinning it reads as a generic fan or propeller, which:
- destroys the perceived single-source origin of the heads (the mythic Hydra's shared core),
- dilutes the emerald/bio-organic identity into generic "tech spinner" motion,
- contradicts the frozen motion system in `13_MOTION_SYSTEM`.

**Consequently, no rotating asset is shipped.** No `.spin` animation, no rotating GIF/video, no SMIL `rotate`, no JS `requestAnimationFrame` rotation. This package intentionally contains **zero** rotation files.

Approved motion remains: stroke reveal, outline trace, approved pulse (`loading-loop.svg`), optional idle breathing (`idle-pulse.svg`), and hover lift (`hover.svg`).
