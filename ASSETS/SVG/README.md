# SVG — Production Vector Variants

Direct-use SVGs derived from the certified master (same geometry, same viewBox).

| File | Use |
| --- | --- |
| `hydra-mark-emerald-fill.svg` | Emerald fill `#10b981` — navbar/hero/footer |
| `hydra-mark-emerald-outline.svg` | Emerald outline — dividers/accents |
| `hydra-mark-currentcolor.svg` | `currentColor` — theme-adaptive |
| `hydra-mark-v4-mask.svg` | Safari mask icon (black, transparent) |
| `hydra-mark-v4-favicon.svg` | Favicon source |

Glow is never baked in; use the CSS utility `.hydra-mark-glow` on the site.
