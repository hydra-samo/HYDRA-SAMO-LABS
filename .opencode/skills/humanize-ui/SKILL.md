# Humanized Editorial Guidelines
1. BANNED: Monospace code eyebrows (`// SECTION`), cyan accents (`#00FFCC`), solid flat bright CTAs, and SaaS comparison matrices.
2. BUTTONS: Deep obsidian glass (`bg-white/[0.04]`), fine emerald border (`border-emerald-500/30`), and soft ambient glow on hover (`shadow-[0_0_20px_rgba(16,185,129,0.2)]`).
3. TYPOGRAPHY: High contrast, un-cluttered, clean off-white titles with max 1-2 words emphasized in Mythic Emerald (`#10b981`).
4. CODE: Always use `cn()` from `src/lib/utils.ts` and relative path imports.
